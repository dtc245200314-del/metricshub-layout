# MetricsHub — hoạt động 447

Mở `metricshub_ui/index.html` bằng trình duyệt hoặc Live Server. Dùng Flexbox cho navbar, CSS Grid ba cột cho bento và Bootstrap cho pricing. Dữ liệu biểu đồ và giá là dữ liệu minh họa. Phân tích lựa chọn tại `layout_strategy.md`.

Mã tự triển khai với trợ giúp Codex. Bootstrap 5.3.8 lấy qua CDN chính thức theo tài liệu https://getbootstrap.com/docs/5.3/ (MIT). Cần mạng để tải CSS Bootstrap.
